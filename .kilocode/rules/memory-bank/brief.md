# Brief - TNT Calendar Bot

## Цель проекта
Разработка Telegram бота для управления календарем событий.

## Основные требования
- Telegram бот на Python
- Современная асинхронная архитектура
- Простая и понятная структура кода
- Легкость в расширении функционала
- Качественная документация

## Ключевые функции
1. Базовые команды бота (/start, /help, /calendar)
2. Управление календарем событий
3. Уведомления о событиях
4. Интеграция с внешними календарями (будущая функция)

## Ограничения
- Только для Telegram платформы
- Python 3.9+
- Использование официального Telegram Bot API

## Целевая аудитория
Пользователи, которым нужен удобный способ управления своим календарем через Telegram.
