# Brief - CrossFit Hub Bot

## Цель проекта
Разработка Telegram-бота "CrossFit Hub" для небольшого кроссфит-зала - централизованного хаба для управления расписанием и бронированием тренировок.

## Основные требования
- Интуитивно понятный интерфейс через Telegram
- Мультиязычность: RU, UA, EN, DE, GE
- Чёткое разделение прав доступа (Атлет, Тренер, Супер Админ)
- Надёжное хранение данных
- Современная асинхронная архитектура на Python

## Ключевые функции

### 1. Для Атлетов (🏋️‍♂️):
- Просмотр расписания на выбранный день
- Запись на тренировку (максимум 2 в день)
- Отмена записи
- Просмотр своих записей
- Ограничение: запись только на Сегодня и Завтра

### 2. Для Тренеров (🤸‍♀️):
- Бронирование слотов под свои тренировки
- Просмотр наполненности классов (общий + детальный)
- Добавление/удаление участников на занятие (Coach's Override)

### 3. Для Супер Администратора (👑):
- Глобальное управление расписанием (добавление/удаление/редактирование тренировок)
- Управление правами пользователей (назначение/снятие статуса Тренера)

## Ограничения
- Только для Telegram платформы
- Python 3.9+
- Временно максимум людей на занятие: 999
- Запись возможна только на текущий день (не раньше текущего времени) и завтра
- Максимум 2 записи в один календарный день для атлета

## Целевая аудитория
- **Атлеты**: Участники кроссфит-зала, желающие удобно записываться на тренировки
- **Тренеры**: Инструкторы, управляющие своими классами
- **Администратор**: Владелец/менеджер зала, управляющий всей системой

## Технический стек
- Telegram Bot API (python-telegram-bot)
- SQLAlchemy + SQLite/PostgreSQL для хранения данных
- Python 3.9+ с асинхронной архитектурой

## Этапы разработки

### Фаза 1 (MVP):
- Модели данных (User, Workout, Booking)
- Основное меню Атлета на русском языке
- Просмотр расписания
- Запись/отмена записи

### Фаза 2:
- Функционал для Тренеров
- Функционал для Супер Админа
- Полная мультиязычность

### Фаза 3:
- Уведомления и напоминания
- Статистика и аналитика
- Интеграция с внешними сервисами
