# Product - TNT Calendar Bot

## Зачем существует этот проект

TNT Calendar Bot создан для решения проблемы управления личным календарем через удобный и привычный интерфейс Telegram. Многие пользователи проводят значительное время в Telegram и хотят иметь возможность быстро проверять и управлять своими событиями без переключения между приложениями.

## Проблемы, которые решает

1. **Доступность**: Календарь всегда под рукой в Telegram
2. **Простота**: Не требуется установка дополнительных приложений
3. **Уведомления**: Напоминания о событиях приходят прямо в Telegram
4. **Кроссплатформенность**: Работает на любом устройстве с Telegram

## Как это должно работать

### Основной сценарий использования

1. Пользователь запускает бота командой `/start`
2. Бот приветствует пользователя и показывает доступные команды
3. Пользователь может:
   - Просмотреть календарь (`/calendar`)
   - Добавить новое событие
   - Получить напоминания о предстоящих событиях
   - Редактировать или удалять события

### Взаимодействие с пользователем

- **Команды**: Простые текстовые команды для базовых действий
- **Кнопки**: Inline-клавиатура для выбора дат и времени
- **Уведомления**: Автоматические напоминания о событиях

## Цели пользовательского опыта

1. **Интуитивность**: Пользователь должен понимать, как работать с ботом, без инструкций
2. **Скорость**: Быстрое добавление и просмотр событий
3. **Надежность**: Бот должен работать стабильно 24/7
4. **Дружелюбность**: Приятный и понятный интерфейс с эмодзи и понятными сообщениями

## Текущее состояние

На данный момент реализован базовый каркас бота с:
- Обработкой команд `/start`, `/help`, `/calendar`
- Структурой проекта для легкого расширения
- Системой конфигурации через переменные окружения
- Обработкой ошибок

## Планы развития

1. Реализация полноценного календаря с просмотром по дням/неделям/месяцам
2. Добавление, редактирование и удаление событий
3. Система напоминаний
4. Повторяющиеся события
5. Интеграция с Google Calendar / iCal
6. Возможность делиться событиями с другими пользователями
