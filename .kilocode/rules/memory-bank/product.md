# Product - CrossFit Hub Bot

## Зачем существует этот проект

CrossFit Hub создан для решения проблемы управления расписанием и записями в небольшом кроссфит-зале. Традиционные системы бронирования часто избыточны и дороги для малого бизнеса, а управление через Excel таблицы или группы в соцсетях неудобно и приводит к путанице.

## Проблемы, которые решает

### Для Атлетов:
1. **Доступность**: Расписание всегда под рукой в Telegram
2. **Простота записи**: Запись на тренировку в пару кликов
3. **Контроль**: Видно количество записавшихся, можно отменить запись
4. **Прозрачность**: Понятно, на какие тренировки записан

### Для Тренеров:
1. **Планирование**: Легко бронировать слоты под свои классы
2. **Контроль наполненности**: Видно, сколько людей записалось
3. **Гибкость**: Возможность добавлять/удалять участников вручную
4. **Обзор**: Быстрый просмотр своего расписания

### Для Администраторов:
1. **Централизованное управление**: Полный контроль над расписанием
2. **Управление доступом**: Назначение тренеров
3. **Масштабируемость**: Легко добавлять новые тренировки
4. **Автоматизация**: Снижение ручной работы

## Как это должно работать

### Основной сценарий для Атлета

1. **Первый запуск**:
   - Пользователь запускает бота `/start`
   - Выбирает язык интерфейса
   - Автоматически получает роль "Атлет"

2. **Просмотр расписания**:
   - Выбирает запись на тренировку и день (**7 дней от сегодня**; на сегодня скрываются уже прошедшие занятия)
   - Видит список тренировок с информацией:
     - Время
     - Тренер
     - Записалось: 5 из 12
     - Кнопка "Записаться" или "❌ Занято" (если лимит)

3. **Запись на тренировку**:
   - Нажимает "Записаться"
   - Система проверяет:
     - ✅ Не больше **настраиваемого** числа активных записей на **календарный день** (значение задаёт админ в веб-панели, дефолт 2)
     - ✅ Есть свободные места (`max_participants` на тренировке)
     - ✅ Тренировка не в прошлом
   - Подтверждение: "✅ Вы записаны на тренировку X в HH:MM"

4. **Управление записями**:
   - Выбирает "📋 Мои записи"
   - Видит список своих записей
   - Может отменить любую запись

### Сценарий для Тренера

1. **Бронирование слота**:
   - Выбирает "🗓️ Забронировать слот"
   - Выбирает дату, время, тип тренировки
   - Система создаёт тренировку

2. **Просмотр наполненности**:
   - Режим "Обзор дня": видит все свои тренировки и количество записей
   - Режим "Детали": видит имена всех записавшихся

3. **Управление участниками**:
   - Может добавить атлета вручную (обход лимитов)
   - Может удалить атлета (например, за неявку)

### Сценарий для Администратора

1. **Управление расписанием**:
   - Создание новых тренировок
   - Редактирование существующих (время, название, лимит)
   - Удаление тренировок

2. **Управление правами**:
   - Назначение пользователя Тренером
   - Снятие статуса Тренера

## Взаимодействие с пользователем

### Принципы UX:
1. **Минимум текста**: Использование эмодзи и кратких сообщений
2. **Inline-клавиатуры**: Все действия через кнопки
3. **Быстрый доступ**: Главное меню всегда доступно через команду или кнопку
4. **Feedback**: Подтверждение каждого действия
5. **Ошибки**: Понятные сообщения об ошибках с подсказками

### Структура меню:

**Атлет:**
```
[Главное меню]
├── 📝 Записаться (выбор дня в пределах недели)
├── 📋 Мои записи
├── ⚙️ Настройки
│   ├── Уведомления вкл/выкл
│   └── 🌐 Язык
└── ℹ️ Помощь
```

**Тренер** (дополнительно):
```
[Меню Тренера]
├── 🗓️ Забронировать слот
├── 👥 Мои классы
│   ├── Обзор дня
│   └── Детали класса
└── ➕ Добавить участника
```

**Админ** (дополнительно):
```
[Меню Админа]
├── ⚙️ Управление расписанием
│   ├── ➕ Создать тренировку
│   ├── ✏️ Редактировать
│   └── 🗑️ Удалить
└── 👤 Управление правами
    └── 🎓 Назначить тренера
```

## Цели пользовательского опыта

1. **Скорость**: Запись на тренировку за 3 тапа
2. **Ясность**: Всегда понятно, что происходит
3. **Надёжность**: Система не теряет записи
4. **Мультиязычность**: Каждый пользователь видит интерфейс на своём языке
5. **Доступность**: Работает 24/7

## Текущее состояние

Рабочий гибрид: бот (запись атлетов, просмотр для тренеров/админов) + **веб-панель** для управления расписанием, пользователями, шаблоном, картинкой расписания и **настройкой дневного лимита записей**. Уведомления в Telegram с учётом пользовательского флага; вход в веб по логину (ID или username) и секрету из окружения.
