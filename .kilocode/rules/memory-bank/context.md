# Context - Текущее состояние проекта

## Текущий фокус работы

Завершена реализация MVP для атлетов И админ-панели! Бот полностью функционален:
- Атлеты: просмотр расписания, запись на тренировки, отмена записей
- Админы: создание расписания, управление пользователями, просмотр статистики

## Как запустить проект

1. **Установить зависимости**:
```bash
pip install -r requirements.txt
```

2. **Настроить `.env`**:
```bash
cp .env.example .env
# Отредактировать .env, добавить токен бота
```

3. **Создать тестовые данные** (опционально):
```bash
# Отредактировать create_test_data.py - заменить telegram_id на свой
python create_test_data.py
```

4. **Запустить бота**:
```bash
python main.py
```
