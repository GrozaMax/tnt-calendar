# Context - Текущее состояние проекта

## Текущий фокус работы

Проект только что инициализирован. Создана базовая структура Telegram бота на Python с использованием библиотеки `python-telegram-bot`.

## Последние изменения

**Дата**: 27 октября 2025

### Созданные файлы и структура:

1. **Конфигурация проекта**:
   - `requirements.txt` - зависимости проекта
   - `.env.example` - пример файла с переменными окружения
   - `.gitignore` - игнорируемые файлы для git
   - `README.md` - документация проекта

2. **Исходный код**:
   - `main.py` - точка входа в приложение
   - `src/bot.py` - главный модуль бота с классом `TelegramBot`
   - `src/config.py` - конфигурация и валидация переменных окружения
   - `src/handlers/base.py` - базовые обработчики команд

3. **Реализованные команды**:
   - `/start` - приветствие и список команд
   - `/help` - справка по использованию
   - `/calendar` - заглушка для будущего функционала календаря

4. **Обработка ошибок**:
   - Глобальный обработчик ошибок
   - Валидация конфигурации при запуске

## Важные заметки

- Проект использует асинхронную архитектуру (async/await)
- Все обработчики должны быть асинхронными функциями
- Конфигурация загружается из `.env` файла
- Логирование настроено через стандартный модуль `logging`
- Структура проекта позволяет легко добавлять новые обработчики команд

## Известные ограничения

- Пока нет базы данных - события не сохраняются
- Календарь - это только заглушка
- Нет системы напоминаний
- Нет обработки callback-запросов от inline-кнопок
