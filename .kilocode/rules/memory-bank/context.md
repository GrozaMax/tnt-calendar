# Context - Текущее состояние проекта

## Текущий фокус работы

✅ **ЗАВЕРШЕНА МИГРАЦИЯ НА ГИБРИДНУЮ АРХИТЕКТУРУ** (1 декабря 2025)

Проект теперь состоит из двух частей:
1. **Telegram бот** - для атлетов (просмотр и записи)
2. **Веб-интерфейс (FastAPI)** - для тренеров и админов (управление)

Функционал:
- ✅ Атлеты: просмотр расписания, запись на тренировки, отмена записей (Telegram)
- ✅ Тренеры: просмотр своих тренировок в Telegram, управление в вебе
- ✅ Админы: просмотр всего в Telegram, полное управление в вебе

## Как запустить проект

### Быстрый старт

См. подробную инструкцию в [START_HERE.md](START_HERE.md)

### Кратко:

1. **Установить зависимости**:
```bash
pip install -r requirements.txt
```

2. **Настроить `.env`**:
```bash
cp .env.example .env
# Добавить токен бота и другие настройки
```

3. **Запустить Telegram бота**:
```bash
python main.py
```

4. **Запустить веб-интерфейс** (в отдельном терминале):
```bash
python run_web.py
```

5. **Войти в веб-интерфейс**:
- Откройте http://localhost:8000
- Используйте Telegram ID и секретный код: `secret123`

### Создание тестовых данных:

```bash
# Создать пользователей
python create_test_data.py

# Создать расписание (или используйте веб-интерфейс)
python create_weekly_schedule.py
```
