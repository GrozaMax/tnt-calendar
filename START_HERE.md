# 🏋️ CrossFit Hub - Быстрый старт

Добро пожаловать в CrossFit Hub! Этот проект состоит из двух частей:
- **Telegram бот** для атлетов (записи на тренировки)
- **Веб-интерфейс** для тренеров и админов (управление расписанием)

## 📦 Установка

### 1. Клонируйте репозиторий

```bash
git clone <your-repo>
cd tnt-calendar
```

### 2. Создайте виртуальное окружение

```bash
python3 -m venv venv
source venv/bin/activate  # macOS/Linux
# или
venv\Scripts\activate  # Windows
```

### 3. Установите зависимости

```bash
pip install -r requirements.txt
```

### 4. Настройте переменные окружения

Скопируйте `.env.example` в `.env` и заполните:

```env
# Telegram Bot Token (получите у @BotFather)
TELEGRAM_BOT_TOKEN=your_bot_token_here

# База данных
DATABASE_URL=sqlite+aiosqlite:///./crossfit_hub.db

# Telegram IDs админов (через запятую)
ADMIN_TELEGRAM_IDS=123456789

# Веб-интерфейс
WEB_HOST=0.0.0.0
WEB_PORT=8000
WEB_DEBUG=true
```

## 🚀 Запуск

### Telegram бот

```bash
python main.py
```

### Веб-интерфейс

```bash
python run_web.py
```

Или через uvicorn:

```bash
uvicorn web.main:app --reload
```

Веб-интерфейс будет доступен по адресу: http://localhost:8000

## 📱 Первые шаги

### 1. Создайте первого пользователя

Запустите бота в Telegram: `/start`

### 2. Сделайте себя админом

Найдите ваш Telegram ID:
- Напишите боту @userinfobot
- Скопируйте ваш ID

Добавьте ID в `.env`:
```env
ADMIN_TELEGRAM_IDS=ваш_telegram_id
```

Перезапустите бота.

### 3. Войдите в веб-интерфейс

1. Откройте http://localhost:8000
2. Введите ваш Telegram ID
3. Введите секретный код: `secret123`
4. Нажмите "Войти"

### 4. Создайте расписание

В веб-интерфейсе:
1. Перейдите на вкладку "🗓️ Расписание"
2. Выберите количество недель
3. Нажмите "Создать расписание"

Или создайте тренировку вручную:
1. Вкладка "📅 Тренировки"
2. Кнопка "➕ Создать тренировку"

## 🎭 Роли пользователей

### Атлет (Athlete) 🏋️
- Просмотр расписания
- Запись на тренировки
- Отмена записей
- Доступ: только Telegram бот

### Тренер (Trainer) 🤸‍♀️
- Всё что у атлета
- Просмотр своих тренировок и участников (в боте)
- Создание/редактирование своих тренировок (в вебе)
- Доступ: Telegram бот + веб-интерфейс

### Администратор (Admin) 👑
- Полный доступ ко всем функциям
- Управление тренировками (в вебе)
- Управление пользователями (в вебе)
- Просмотр расписания и статистики (в боте)
- Доступ: Telegram бот + веб-интерфейс

## 🐛 Частые проблемы

### ModuleNotFoundError: No module named 'telegram'

```bash
pip install -r requirements.txt
```

### База данных не создаётся

```bash
# Удалите старую БД и пересоздайте
rm crossfit_hub.db
python main.py
```

### Не могу войти в веб-интерфейс

Проверьте:
1. Ваш пользователь есть в БД (запустите бота `/start`)
2. Ваша роль - Trainer или Admin (не Athlete)
3. Секретный код: `secret123`
